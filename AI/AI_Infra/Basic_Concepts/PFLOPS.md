**PFLOP/s** 是 **Peta Floating-Point Operations Per Second** 的缩写，中文叫作**每秒千万亿次浮点运算**，是衡量计算设备（尤其是 GPU、超级计算机和 AI 集群）浮点计算性能的单位。

### 1. PFLOP/s 的含义

拆开来看：

- **Peta (P)**：\\(10^{15}\\)，即千万亿（Quadrillion）。
- **FLOP**：Floating-Point Operation，即一次浮点运算。
- **/s**：Per Second，即每秒。

因此：

\\[ 1\ \text{PFLOP/s} = 10^{15}\ \text{FLOP/s} \\]

也就是每秒执行 1,000 万亿次浮点运算。

### 2. 常见计算性能单位对比

| 单位      | 每秒浮点运算次数      |
| ------- | ------------- |
| GFLOP/s | \\(10^9\\)    |
| TFLOP/s | \\(10^{12}\\) |
| PFLOP/s | \\(10^{15}\\) |
| EFLOP/s | \\(10^{18}\\) |

相邻单位相差 1000 倍。

### 3. 在 AI 大模型领域的应用

PFLOP/s 经常用来描述 GPU 或 GPU 集群的计算能力。

例如：

- 一张 GPU：可能拥有数十到数百 TFLOP/s 的计算能力。
- 一个 GPU 集群：可能达到数 PFLOP/s 甚至数百 PFLOP/s。
- 超大规模 AI 训练集群：可能达到 EFLOP/s 级别。

需要特别注意：**PFLOP/s 必须结合数据精度（Precision）来看。**

例如，同一张 GPU 的理论峰值性能可能分别是：

| 精度          | 性能   |
| ----------- | ---- |
| FP64        | 较低   |
| FP32        | 较高   |
| TF32        | 更高   |
| FP16 / BF16 | 更高   |
| FP8         | 更高   |
| FP4         | 通常更高 |

所以，当你看到 GPU 的性能指标是 10 PFLOP/s 时，一定要确认它指的是 FP64、FP32、BF16、FP8 还是 FP4。

### 4. 一个容易混淆的概念

- **FLOPs**：执行了多少次浮点运算，是计算量。
- **FLOP/s**：每秒执行多少次浮点运算，是计算速度。
- **PFLOP/s**：每秒千万亿次浮点运算，是计算速度单位。

在 LLM 推理和训练性能分析中，通常还会看到 **MFU（Model FLOPs Utilization）**，它衡量模型实际计算吞吐量占 GPU 理论峰值计算能力的比例。
